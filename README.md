# PRP Portal – Recruiter Registration

## Run in VS Code
1. Open this folder in VS Code (`File > Open Folder`).
2. Open the terminal (`Ctrl + ~`) and run:

```
npm install
npm run dev
```

The app opens at http://localhost:5173
